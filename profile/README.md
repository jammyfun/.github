### 코딩, 세상에서 가장 즐거운 놀이

</div>

<br>

**AI로 돈 버는 법을 팔지 않습니다.**
**개발을 사랑하며, 그걸로 먹고사는 법을 팝니다.**

만드는 게 즐겁고, 조직 밖에서 그걸로 먹고살려는 개발자 — Self Developer를 위한 교육과 콘텐츠를 만듭니다.

<br>

## 여기 있는 것

만들어서 실제로 쓰고, 파는 것들의 코드입니다. 데모가 아닙니다.

- **따로 또 같이** — 아내와 매일 쓰는 커플 여행 앱 (Expo · React Native)
- **컷앤커밋 예제** — [유튜브 채널](https://youtube.com/@cutncommit) 에피소드에서 다룬 코드

<br>

## 이런 분께는 맞지 않습니다

- AI로 빠르게 돈을 벌고 싶은 분
- 취업 포트폴리오가 필요한 분
- 코딩 없이 결과만 원하는 분

만드는 과정 자체가 즐겁지 않다면, 여기서 얻을 게 없습니다.
